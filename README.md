# Lucky Spin Playable Ad 🎰

Lucky Spin is a lightweight HTML5 playable ad that simulates a casino-style prize wheel

## Demo

🌐 https://vicadin.github.io/lucky-spin/

## Tech Stack

- TypeScript
- Vite
- HTML5
- CSS3
- SVG
- RequestAnimationFrame
- GitHub Pages

### Installation & Execution

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
